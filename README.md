# Sistema de Gestion para Biblioteca Universitaria

Este repositorio contiene el codigo fuente en Python del sistema de gestion de biblioteca.

Implementa los siguientes componentes:

* Gestion de libros, revistas y estudiantes.
* Clases abstractas y herencia.
* Polimorfismo en el procesamiento de materiales.
* Manejo de excepciones personalizadas para el control de errores.
